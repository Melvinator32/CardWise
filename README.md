# CardWise

A single-file credit card and spend dashboard: categorizes transactions, tracks
points earn rates and card-level value, monitors statement credits against their
targets, and flags spend that went on a lower-earning card than it could have.
No build step and no dependencies.

## Run it
Open `index.html` in any browser, or serve the folder:

    python3 -m http.server 8000

then visit http://localhost:8000

## Demo data

**Every transaction in this app is fabricated.** The 1,900 transactions, their
merchants, amounts, dates and the statement-credit history are all generated by
`tools/make-demo-data.mjs` from a fixed seed. No real account, statement, or
spending history is included, and the portfolio timeline (which cards are held,
when they were opened) is invented too.

Card names, annual fees, earn multipliers and credit structures are real
published product terms, kept so the dashboard demonstrates something meaningful.

To regenerate the dataset:

    node tools/make-demo-data.mjs

It rewrites the `BAKED` object inside `index.html` in place. The seed is fixed,
so the output is identical every run unless you change it.
